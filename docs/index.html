常见问题

开始之前，可能想知道

音频会上传到服务器吗？

不会。实时音频帧始终在本机完成处理。账号、会员与版本检查需要联网，但不会上传你的声音。

没有自己的音色模型，可以使用吗？

可以。完整安装包包含可用的默认模型与索引，也可以随时换成自己的 RVC 音色资源。

安装前需要准备 Python 或 CUDA 吗？

不需要。离线安装包已经包含程序与所需运行环境，按安装向导完成即可。

可以先免费体验吗？

可以。未开通会员的设备每天有 1 小时免费实时变声额度，只在实时音频流运行时计时。
