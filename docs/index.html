开始之前，你可能想知道

遇到其他问题，可在 GitHub 查看完整文档或提交 Issue。

音频会上传到服务器吗？

不会。所有实时音频帧与文件变声推理均在你本机完成，声音数据不会上传到服务器。账号登录、会员同步、音色商城下载与版本检查需要联网。

没有自己的音色模型，安装后能直接用吗？

可以。安装包已自带莞宁、可棠、绮音、悠汐等多款免费内置音色，打开就能先试听再开麦；你也可以在「音色商城」获取更多音色，或在「设置」里导入自己的 .pth / .index 或模型 ZIP 压缩包。

每天 1 小时免费额度怎么计时？和会员有什么区别？

未开通会员时，每台设备每天有 1 小时免费实时变声额度，只有点击「开始实时变声」运行期间才会计时，并在本地时间次日 00:00 自动刷新。开通会员后，有效期内实时变声不限时，并可使用商城里的会员专属音色。

怎么让游戏、QQ、Discord 或 OBS 听到变声后的声音？

安装程序可选一键安装标准版 VB-CABLE 虚拟音频线（装完需重启电脑）。在 RVC Studio 里将输出设备选为 CABLE Input，再去游戏或聊天软件的麦克风设置里选 CABLE Output，对方就能直接听到变声。

安装前需要装 Python 或 CUDA 吗？AMD 显卡可以用吗？

不需要提前装 Python 或 CUDA Toolkit，离线安装包已完整内置。显卡方面，当前正式安装包仅支持 NVIDIA RTX 20/30/40/50 系列（建议驱动 572.61+），暂不支持 AMD 显卡、Intel 核显或纯 CPU 实时运行。

下载时该选哪个文件？遇到 Windows SmartScreen 提示安全吗？

前往最新版本发布页后，直接下载单文件 RVC-Studio-NVIDIA-Setup.exe 即可，无需分卷。由于个人开源项目安装包暂未购买商业代码签名证书，Windows SmartScreen 可能会弹出提醒；发布页提供 SHA256SUMS.txt 供校验，且内置的 VB-CABLE 驱动保留了官方数字签名。
